Stylish Text

How fancy text works: characters, not fonts

Fancy text looks like a font, but it is not one. A font changes how the same letter is drawn. Fancy text uses different characters that happen to look like styled letters. This is why you can paste them into a chat or a profile where you cannot choose a font.

Where the letters come from

Unicode, the standard that lists every character a computer can show, has a block of "Mathematical Alphanumeric Symbols". It was made for mathematicians who need a bold x and an italic x to mean different things in one formula. It holds whole alphabets in bold, italic, script, gothic (fraktur), double-struck, sans-serif and monospace, in capitals and small letters. Other blocks hold circled, squared, bracketed and full-width letters. This site picks from those blocks by code point.

What this means in practice

  • The computer sees a different character. A bold "A" made this way is not an A. It is "Mathematical Bold Capital A". Search boxes, spell checkers and sorting treat it as a different letter.
  • The device needs a font that has the character. Most phones and computers do. An old phone may show an empty box. Always look at the result on the device where it will be read.
  • Some letters are missing or borrowed. The script, gothic and double-struck alphabets have gaps in the main block, filled with older characters from another block (the tool does this for you). Small capitals have no true "q" or "x".
  • Only Latin letters and digits change. Hindi, Punjabi, Arabic and other scripts have no such styled characters, so the tool leaves them as they are.

Strikethrough and underline

These are not separate letters. They use "combining" characters that attach to the letter before them: a line through the middle, or a line below. The tool puts one after every letter. Because the mark is a separate character, a name with a combining line in it is twice as long to a computer.

How we check the tables

Every mapping on this site was built from the code point ranges and then compared with the Unicode Character Database that ships with Python. The character name must name the same letter (for example "MATHEMATICAL BOLD SCRIPT CAPITAL Q"), and for the styles that have a compatibility decomposition, converting the styled letter to its plain form (Unicode normalisation NFKC) must give back the original letter. All of them pass.

Questions

Is fancy text a font?

No. It is a set of different Unicode characters that look like styled letters, so it works where you cannot choose a font.

Why does one letter look like a box?

The device has no font with that character. Try another style, or check on a newer phone or computer.
