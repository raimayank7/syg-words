Stylish names for games and bios: pick a style and stay safe

A good stylish name is easy to read, easy to remember and easy to type for a friend who wants to find you. Fancy letters help only with the first. Here is how to get all three.

1. Start with a plain name you like

Make the name before you style it. Short names (4 to 10 characters) work in every style. Mix something personal (a word, a number that matters to you) with something simple. Our username ideas and nickname ideas can help.

2. Pick a style that stays readable

  • Bold, sans-serif bold and monospace are the easiest to read at small sizes.
  • Script and fraktur (gothic) look pretty but need space; small capitals and double-struck sit in between.
  • Circled and squared letters are wide and best for a short tag.

3. Keep a plain version

Friends will type your name to find you or to invite you to a team. If you use a fancy version, tell them the plain spelling, put it in your bio, or keep it in a place where the plain name is searchable.

4. Check the rules

Games, apps and websites set their own rules on special characters and on length, and the rules change. Some count a styled letter as more than one character; some replace or reject it. Try it on the real screen.

5. Do not copy someone else

If you see a team or a creator with a name you like, do not copy it, and do not use names of brands, public figures or other people. Names that pretend to be someone else can get an account banned and can hurt people.

6. Keep it kind

Do not use a style to hide insults, hate or adult words. A word is not harmless because it is written in script letters. This site does not offer such text, and platforms can read the characters.

Questions

How long can a game name be?

It depends on the game, and the limit may count styled letters as more than one character. Check the screen in the game itself.

Can two players have the same fancy name?

That is decided by the game, not by the letters. Many games require a name nobody has taken, so try a different style or add a word.
