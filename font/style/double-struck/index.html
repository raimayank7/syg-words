What double-struck text looks like

The name "Rohan Sharma" becomes ℝ𝕠𝕙𝕒𝕟 𝕊𝕙𝕒𝕣𝕞𝕒. Mathematical styles are the most widely supported fancy letters, because most phones, computers and fonts include the Mathematical Alphanumeric Symbols block.

This style uses 52 letters and 10 digits from the Unicode block Mathematical Alphanumeric Symbols, between U+2102 and U+1D7E1. Digits are also styled.

The main block has gaps for 7 letters (C = U+2102, H = U+210D, N = U+2115, P = U+2119, Q = U+211A, R = U+211D, Z = U+2124): they were already in Unicode as older characters in the Letterlike Symbols block, so the tool uses those. They look the same in the style, but come from a different block and may look slightly different on an old device.

Before you use it

  • It is a set of different characters, not a font, so search and screen readers see other letters than you do. Read where not to use fancy text.
  • Keep a plain version of the name in your bio or message so people can find you.
  • Check the result on the real screen: some apps change or reject special characters.

Questions

Is double-struck text a font?

No. It is made of different Unicode characters, so it can be pasted where you cannot choose a font.

Will it show on every phone?

Most, not all. Older devices may show empty boxes. Look at the result on the screen where it will be read.
