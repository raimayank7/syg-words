How to use this list

Names are grouped by theme on the theme pages, and gathered here so that you can search across all of them. A word such as "chai" finds the names from family, friends, office and food groups at once. Read a few aloud, change a word or a year to make a name yours, and ask the group to vote.

Many names here are written in Hinglish (Hindi in English letters), because that is how most Indian groups name themselves. See the guide to Hinglish and native-script names if you want to write one in Devanagari or Gurmukhi.
