Name in Scripts

How to type your name so the tool gets it right

The tool reads what you type as sounds. English spelling hides many sounds: the "a" at the end of "Priya" is long, the "u" in "Rahul" is short but the "a" before it is long, and nobody can tell from the letters alone. A few simple habits make the result much better.

Write long vowels twice

Hindi, Punjabi and the other Indian languages tell a short vowel from a long one, and a name is spelled with the long one when it is long. So type "aa" for a long a, "ee" for a long i, "oo" for a long u. "Raahul" gives राहुल and "Priyaa" gives प्रिया. A single "a" at the end of a word is already treated as long, because most Indian names that end in a do.

Know when a vowel is not there

In Hindi the short a inside a word is often not said: the name "Mayank" has the sounds ma-yank, not ma-ya-na-ka. The tool does not add a vowel sign for a single "a" inside a word, so "mayank" works. If a vowel is said but spelling would hide it, type it in. "Simran" is said "simran" in English but "simaran" in Punjabi, and the tool writes the vowel only if you type the "a".

Single sounds with two letters

The pairs "sh", "ch", "kh", "gh", "th", "dh", "ph", "bh" and "jh" are read as one sound, which is right for nearly every name. The tool cannot split a pair, so for a rare name where the two letters are separate sounds, use the nearest spelling that does not put them side by side.

Double letters

A double consonant is written as a doubled sound with a linking sign in the Indian scripts, as in "Mohammad" (मोहम्मद) or "Lakshmi" (लक्ष्मी). In Japanese a double consonant is shown by the small ッ, and in Korean it is ignored. Type double letters only when the name really has them.

The letters that mean different things

  • c is k before a, o and u and s before e, i and y.
  • j is the sound in "jam"; in Russian it is written with two letters, дж.
  • z uses the nukta dot in Hindi (ज़).
  • w is a sound like "v" in Hindi (व), and a separate sound in Japanese and Korean.

Check the result

If the result looks wrong, change the spelling you typed and try again: you cannot break anything. If the name matters, have a reader check it.

Questions

Why does the tool write my name differently from my passport?

A passport spells the name in Latin letters. Another script writes the sounds. They are two descriptions of one name, and there is no rule that makes them match exactly.

Should I type a nickname or a full name?

Either works. Type each name as you say it, with a space between names.
