Write your name in other scripts

Type a name and see it in Hindi, Punjabi, Urdu, Arabic, Russian, Japanese, Korean, runes, Morse and braille. Copy it, send it, or save it as a picture. Free, no login, nothing leaves your browser.

Written by sound and approximate. For long vowels type "aa", "ee" or "oo" (for example Raahul). Have a reader of the script check it before you print or engrave it.

    How it works

    The tool listens, in a way, to the letters you type: it breaks the name into sounds and writes each sound with the closest letter of the other script. It follows the habits of each script. Japanese writers add a vowel after a lone consonant, Arabic and Urdu leave out short vowels, Hindi joins consonants into conjuncts, and Korean builds square syllable blocks. The page for each script lists its rules and shows thirty example names, so you can see before you type whether the script suits your name.

    Before you use the result

    A name in another script is a matter of sound and custom, and careful people write the same name in different ways. Treat the card as a first draft. For a tattoo, a gift, a card or an engraving, ask a reader of the script to check it, and read the guide on documents and tattoos. For an official form, use the spelling the office gives you. The typing tips explain how to get a better result from the tool.

    Questions

    Is this my name in Chinese?

    No. Chinese names use characters chosen for their meaning, so a tool cannot write them honestly. We offer scripts that write sounds.

    Is my name stored?

    No. The name stays in your browser. The address of the page changes to carry your name only on your own device, so you can bookmark or share the link.

    Why does the picture button need a moment?

    It waits for the right font to load, then draws your name on a square picture you can save and share.
