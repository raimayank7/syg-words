Your name in Arabic

How your name looks in Arabic, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Arabic is written from right to left in a cursive script in which most letters join. Like Urdu it writes consonants and long vowels and leaves out short vowels. Arabic names are usually real words (Noor means light, Ali means high), so a name that is not Arabic is written by sound and may not look like an Arabic name.

The tool writes the consonants of your name in Arabic letters and uses alif, ya and waw for long vowels. Sounds that Arabic does not have, such as p and v, are written with the nearest letters, ب and ف. The letter g is written as ج, as in Egyptian speech. A short vowel in the middle of the name is left out, and a final a is written ة. This is a first draft: ask an Arabic reader before using it for anything permanent.

Arabic names are real words with fixed spellings. A name from another language is only an approximation.

Write my name

How the tool writes it

  • Letters are chosen by sound: ب for b and p, ف for f and v, ج for j and g, ك for k and c, and تش for ch.
  • The sounds "kh", "dh", "th" and "sh" are written with خ, ذ, ث and ش.
  • Long vowels "aa", "ee", "oo" are written with alif, ya and waw. Short vowels in the middle of a word are left out, as Arabic spelling does.
  • A word that starts with a vowel begins with alif, and a final "a" is written ة.

How this script was checked

Each consonant checked against the Unicode letter name (for example SHEEN for sh); vowel handling follows the usual practice of leaving out short vowels, which is our rule, not a table. The check covered 20 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Arabic. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I write my name in Arabic?

Use the tool and take the Arabic card, then ask an Arabic reader to check it.

Why does the name look different from my English spelling?

Arabic writes sounds, and leaves short vowels out. The same letters can be read several ways.
