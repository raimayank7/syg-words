Your name in Braille

How your name looks in Braille, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Braille is a system of raised dots that blind and low-vision people read with their fingers. Each cell has six dots in two columns of three, and each pattern stands for a letter, a number or a short word. It was invented by Louis Braille in 1824 and is used worldwide.

The tool writes your name in standard English uncontracted braille (Grade 1) using the Unicode braille patterns, with the capital sign ⠠ in front of the name. The patterns shown on a screen are drawn, not raised, so you cannot feel them. Braille for Indian languages uses a different assignment of patterns (Bharati Braille), which this tool does not produce.

Write my name

How the tool writes it

  • Each letter A to Z has its standard six-dot pattern, checked against the dot numbers in the Unicode braille patterns.
  • A capital sign ⠠ is placed in front of the name.
  • This is English Grade 1 braille, not Bharati Braille for Indian languages.

How this script was checked

Dot numbers compared with the Unicode braille pattern names (test_engine.py). The check covered 26 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Braille. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

Can this be printed for a blind person to read?

No. Braille must be embossed. The screen version shows the patterns only.

Is the braille for Hindi the same?

No. Indian languages use Bharati Braille, which assigns the patterns differently.
