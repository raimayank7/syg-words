Your name in Greek

How your name looks in Greek, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

The Greek alphabet has 24 letters and gave rise to the Latin and Cyrillic alphabets. A name is written by sound, so "Peter" can be written Πέτρος in a Greek form or Πίτερ by sound.

The tool writes the sounds of the name with Greek letters: "th" is θ, "ph" is φ, "ch" is χ, "u" is ου and "y" before a vowel is γι. A final s becomes ς. It does not add Greek accents or the endings that Greek names take, so the card is a plain phonetic version that a Greek speaker will read aloud close to the original.

Write my name

How the tool writes it

  • "th" is θ, "ph" is φ, "kh" and "ch" are χ, "ps" is ψ, "ng" is γγ.
  • "u" and "w" are ου; "oo" is ου; "y" before a vowel is γι and elsewhere υ; "j" is τζ.
  • The letter s becomes ς at the end of a word.
  • Greek accents are not added.

How this script was checked

Greek written back to Latin with the transliterate package; consonants compared. The check covered 57 items; it disagreed on 3: sachin: σατσιν (reads back as satsin); harjot: χαρτζοτ (reads back as chartzot); michael: μιτσαελ (reads back as mitsael).

The English "ch" is written τσ (as in Greek spellings of Charlie or Sachin), which fails for names where ch is a k sound, such as Michael; and j is written τζ, which the package reads back as "tz".

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

For example, Aarav is written αραβ and Ananya is written ανανγια in this tool. The table below lists thirty names, so you can check how a name like yours is handled.

Check it with a reader

Read the result aloud to someone who reads Greek. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I write my name in Greek?

Use the tool and take the Greek card.

Why are there no accents?

The tool writes sounds only. Greek spelling marks the stressed syllable with an accent, which depends on how the name is stressed.
