Your name in Korean (Hangul)

How your name looks in Korean (Hangul), how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Hangul is the Korean alphabet, designed in the 15th century. Its letters are grouped into square blocks, one block for each syllable, so the name Rahul is written as two blocks, 라 and 훌. Foreign names are written in Hangul by sound, following official rules for foreign words.

The tool follows them: k, t, p and ch are written with the strong letters ㅋ, ㅌ, ㅍ, ㅊ, and g, d, b, j with the plain ㄱ, ㄷ, ㅂ, ㅈ. A consonant with no vowel after it takes the neutral vowel ㅡ (크, 트, 프, 스), unless it is n, m, l or ng, in which case it becomes the final letter of the syllable before it. Long vowels are written short. A Korean reader may prefer a different spelling for a name they know.

Write my name

How the tool writes it

  • Each syllable block is built from an opening consonant, a vowel and an optional closing consonant.
  • k, t, p, ch are written ㅋ, ㅌ, ㅍ, ㅊ; g, d, b, j are ㄱ, ㄷ, ㅂ, ㅈ; l and r are ㄹ; "sh" gives the y-vowel blocks 샤, 시, 슈, 셰, 쇼.
  • A lone consonant takes ㅡ (크, 트, 프, 스, 브, 드), but n, m, l and ng join the previous block as closing letters.
  • Long vowels (aa, ee, oo) are written as one short vowel.

How this script was checked

Written back to Latin with the Revised Romanization of Korean (korean-romanizer package); consonants compared. The check covered 57 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Korean. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I write my name in Korean?

Use the tool and take the Hangul card.

Do Koreans pronounce it the same?

Close to it. Korean has no f, v, z or th, so those sounds are written with the nearest Korean ones.
