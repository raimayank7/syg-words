Your name in Kannada

How your name looks in Kannada, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Kannada is the script of Karnataka. It is closely related to Telugu, because both grew from the same old script, and the letters are round and loopy. Like Telugu it has aspirated letters, and Kannada names usually end in a vowel as well.

The tool turns your name into Devanagari and then moves every letter to its Kannada twin. This keeps each sound exactly. A name that ends in a consonant is closed with a virama so that it is read without a final "a". Kannada speakers often add a final u when they say such a name, which the tool does not do.

Write my name

How the tool writes it

  • The name is first written in Devanagari, then every letter is moved to the same letter of this script. The Indian scripts share one order of letters and one set of vowel signs, so the move is exact, and it was checked letter by letter against the Unicode names.
  • A consonant followed by a vowel letter gets the matching vowel sign. A consonant followed by another consonant is joined to it with a virama, which makes a conjunct. A consonant at the end of a word is left bare, as in spoken Hindi ("Rohan" ends in n, not "na").
  • The sounds "sh", "ch", "kh", "gh", "th", "dh", "ph", "bh" and "jh" are single letters. The letter z is written with a nukta dot where the script has one.
  • A nasal n or m before k, g, ch, j, t, d, p or b is written as the anusvara dot, which is how names such as Mayank, Sandeep and Sanjay are customarily written.
  • About 45 common Indian names (listed on the tool page) are looked up in a small list of customary spellings first, because spoken Hindi drops short vowels that spelling keeps ("Rahul" is राहुल).

How this script was checked

Kannada written back to Latin with the indic-transliteration package (ITRANS tables); consonants compared with the usual spelling. The check covered 57 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Kannada. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I write my name in Kannada?

Type your name on the tool page and read the Kannada card.

Is Kannada like Telugu?

The two scripts look alike and share most of their letters, but the languages are different and their words differ.
