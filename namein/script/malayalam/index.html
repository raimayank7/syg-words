Your name in Malayalam

How your name looks in Malayalam, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Malayalam is the script of Kerala. Its letters are circular and it has one of the largest sets of letters among Indian scripts, as it keeps the sounds of Sanskrit as well as its own. Modern printing uses a simplified form that writes many conjunct letters in a single stroke.

The tool moves each letter of your name from Devanagari to its Malayalam twin. A final consonant is closed with the virama sign, which Malayalam shows as the chandrakkala, so that the name is read without a final "a". Malayalam has no nukta, so z and f appear as ordinary letters. For documents, ask a Malayalam reader which form they would use.

Write my name

How the tool writes it

  • The name is first written in Devanagari, then every letter is moved to the same letter of this script. The Indian scripts share one order of letters and one set of vowel signs, so the move is exact, and it was checked letter by letter against the Unicode names.
  • A consonant followed by a vowel letter gets the matching vowel sign. A consonant followed by another consonant is joined to it with a virama, which makes a conjunct. A consonant at the end of a word is left bare, as in spoken Hindi ("Rohan" ends in n, not "na").
  • The sounds "sh", "ch", "kh", "gh", "th", "dh", "ph", "bh" and "jh" are single letters. The letter z is written with a nukta dot where the script has one.
  • A nasal n or m before k, g, ch, j, t, d, p or b is written as the anusvara dot, which is how names such as Mayank, Sandeep and Sanjay are customarily written.
  • About 45 common Indian names (listed on the tool page) are looked up in a small list of customary spellings first, because spoken Hindi drops short vowels that spelling keeps ("Rahul" is राहुल).

How this script was checked

Malayalam written back to Latin with the indic-transliteration package (ITRANS tables); consonants compared with the usual spelling. The check covered 57 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Malayalam. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I write my name in Malayalam?

Type your name on the tool page and read the Malayalam card.

Does Malayalam have a letter for every Hindi sound?

Almost all. The tool uses the Malayalam letter for each Hindi one.
