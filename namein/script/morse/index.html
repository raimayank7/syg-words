Your name in Morse code

How your name looks in Morse code, how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Morse code writes each letter as a pattern of short and long signals, called dots and dashes. It was developed in the 1830s and 1840s for the telegraph and is still used by radio amateurs and in emergencies, because it can be sent by light, sound or tapping.

The tool writes your name letter by letter using the standard international Morse alphabet. Letters are separated by a space and words by a slash. Morse has no letters outside the English alphabet, so accents are dropped. You can copy the dots and dashes and tap them out on a torch or a table to send your name.

Write my name

How the tool writes it

  • Each letter A to Z is written with the standard international Morse pattern.
  • A space separates the letters, and a slash separates words.
  • Letters not in A to Z are skipped.

How this script was checked

Every letter compared with the morse-talk package (international Morse alphabet). The check covered 26 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

Check it with a reader

Read the result aloud to someone who reads Morse code. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

How do I send my name in Morse?

Write the pattern on the tool page. A dot is a short signal, a dash is three times as long.

Is Morse still used?

Yes, by amateur radio operators, in aviation navigation signals, and as an emergency method.
