Your name in Runes (Elder Futhark)

How your name looks in Runes (Elder Futhark), how the tool writes it, and what to check.

The result is written by sound and is approximate. No native reader has checked it. Do not use it on official documents; for anything permanent, ask a reader of the script.

Runes are the old alphabet of Germanic peoples, carved in wood and stone before the Latin alphabet arrived. The oldest set is the Elder Futhark of 24 runes, used from about the 2nd to the 8th century. Rune names sound like words: the first rune ᚠ is called fehu, cattle or wealth.

The tool writes your name rune by rune, using one rune for each sound: ᚨ for a, ᛒ for b, ᚦ for th, ᛜ for ng. The runes had no letters for c, q, x or v, so those use the nearest ones. The result is a fun, readable version, not the way a rune carver would write: the old texts have no fixed spelling, and short vowels were spelled variously. Do not rely on it for a tattoo; check the runes with a reliable source.

A modern, fun version. Not a historical spelling.

Write my name

How the tool writes it

  • Each letter has one rune; "th" is ᚦ and "ng" is ᛜ.
  • c, k and q use ᚲ; x is ᚲᛊ; v and w use ᚹ; y and i use ᛁ.
  • Words are separated by the rune dot ᛫.

How this script was checked

Each letter checked against the Unicode name of the Elder Futhark rune (for example ANSUZ for a, BERKANAN for b); the mapping of v, y, c, q and x to the nearest rune is our own choice. The check covered 23 items; it found no disagreement.

A check like this finds slips in letters and sounds. It cannot say whether a native reader would spell the name this way, so the results stay approximate.

For example, Aarav is written ᚨᚨᚱᚨᚹ and Ananya is written ᚨᚾᚨᚾᛁᚨ in this tool. The table below lists thirty names, so you can check how a name like yours is handled.

Check it with a reader

Read the result aloud to someone who reads Runes. If they say the name as you do, the spelling works. If they would write it differently, ask which spelling they prefer and use that. The guide on documents and tattoos says when a check is essential.

Questions

Is this how a Viking would write my name?

No. It is a modern letter-by-letter version for fun. The old inscriptions are less regular.

Can I use this for a tattoo?

We advise against it without checking with a specialist, because runes were used in many forms and some rune shapes have unintended meanings.
