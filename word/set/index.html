Set: meaning, synonyms and examples

Set is used as a verb (14 senses), noun (12 senses) and adjective (7 senses). Its most common meaning is: Put into a certain place or abstract location.

In Hindi
रखना, तय करना; सेट
Synonyms
put, place, pose, position, lay, determine, specify, define, fix, limit
Opposites
rise
Word family
setting

Set as a verb

  1. Put into a certain place or abstract location.

    “Put your things here.” “Set the tray down.” “Set the dogs on the scent of the missing children.”

    Synonyms: put, place, pose, position, lay · A kind of: move · Kinds: insert, docket, cock, postpose, prepose, step, replace, stratify

  2. Fix conclusively or authoritatively.

    “Set the rules.”

    Synonyms: determine · Kinds: identify, date, value, filiate, format, charge, initialize, tax

  3. Decide upon or fix definitely.

    “Fix the variables.” “Specify the parameters.”

    Synonyms: specify, determine, define, fix, limit · A kind of: choose · Kinds: quantify, name, reset, define

  4. Establish as the highest level or best performance.

    “Set a record.”

    Synonyms: mark · A kind of: lay down

  5. Put into a certain state; cause to be in a certain state.

    “Set the house afire.”

    A kind of: change · Kinds: pitch, keynote

  6. Fix in a border.

    “The goldsmith set the diamond.”

    A kind of: arrange

  7. Make ready or suitable or equip in advance for a particular purpose or for some use, event, etc.

    “Get the children ready for school!” “Prepare for war.” “I was fixing to leave town after I paid the hotel bill.”

    Synonyms: fix, prepare, set up, ready, gear up · A kind of: change · Kinds: socialize, provide, cram, precondition, mount, set up, winterize, summerize

  8. Set to a certain position or cause to operate correctly.

    “Set clocks or instruments.”

    A kind of: adjust · Kinds: reset, advance

  9. Locate.

    “The film is set in Africa.”

    Synonyms: localize, localise, place · A kind of: stage

  10. Disappear beyond the horizon.

    “The sun sets early these days.”

    Synonyms: go down, go under · Opposite: rise · A kind of: descend

  11. Adapt for performance in a different way.

    “Set this poem to music.”

    Synonyms: arrange · A kind of: compose · Kinds: prearrange, put, transpose, table

  12. Put or set (seeds, seedlings, or plants) into the ground.

    “Let's plant flowers in the garden.”

    Synonyms: plant · A kind of: put · Kinds: root, puddle, checkrow, bed, dibble, afforest, replant, tree

  13. Apply or start.

    “Set fire to a building.”

    A kind of: originate

  14. Become gelatinous.

    “The liquid jelled after we added the enzyme.”

    Synonyms: jell, congeal · A kind of: solidify

Set as a noun

  1. A group of things of the same kind that belong together and are so used.

    “A set of books.” “A set of golf clubs.” “A set of teeth.”

    A kind of: collection · Kinds: dentition, singleton, pair, trio, quartet, quintet, sextet, septet

  2. (mathematics) an abstract collection of numbers or symbols.

    “The set of prime numbers is infinite.”

    A kind of: abstraction · Kinds: interval, group, domain, image, universal set, locus, subset, null set

  3. Several exercises intended to be done in series.

    “He did four sets of the incline bench press.”

    Synonyms: exercise set · A kind of: exercise

  4. Representation consisting of the scenery and other properties used to identify the location of a dramatic production.

    “The sets were meticulously authentic.”

    Synonyms: stage set · A kind of: representation · Kinds: scenery

  5. An unofficial association of people or groups.

    “The smart set goes there.” “They were an angry lot.”

    Synonyms: circle, band, lot · A kind of: social group · Kinds: car pool, clique, cohort, conspiracy, horsy set, jet set, party

  6. A relatively permanent inclination to react in a particular way.

    “The set of his mind was obvious.”

    Synonyms: bent · A kind of: inclination

  7. The act of putting something in position.

    “He gave a final set to his hat.”

    A kind of: placement

  8. A unit of play in tennis or squash.

    “They played two sets of tennis after dinner.”

    A kind of: playing period

  9. The process of becoming hard or solid by cooling or drying or crystallization.

    “The hardening of concrete.” “He tested the set of the glue.”

    Synonyms: hardening, solidifying, solidification, curing · A kind of: natural process · Kinds: congealment

  10. The descent of a heavenly body below the horizon.

    “Before the set of sun.”

    A kind of: descent

  11. (psychology) being temporarily ready to respond in a particular way.

    “The subjects' set led them to solve problems the familiar way and to overlook the simpler solution.” “His instructions deliberately gave them the wrong set.”

    Synonyms: readiness · A kind of: cognitive state

  12. Any electronic equipment that receives or transmits radio or tv signals.

    “The early sets ran on storage batteries.”

    A kind of: electronic equipment · Kinds: receiver, transmitter

Set as an adjective

  1. (usually followed by `to' or `for') on the point of or strongly disposed.

    “In no fit state to continue.” “Fit to drop.” “Laughing fit to burst.”

    Synonyms: fit, primed · Similar: ready

  2. Fixed and unmoving.

    “With eyes set in a fixed glassy stare.” “His bearded face already has a set hollow look.” “A face rigid with pain.”

    Synonyms: fixed, rigid · Similar: nonmoving

  3. Situated in a particular spot or position.

    “Valuable centrally located urban land.” “Strategically placed artillery.” “A house set on a hilltop.”

    Synonyms: located, placed, situated · Similar: settled

  4. Set down according to a plan:"a carefully laid table with places set for four people".

    “A carefully laid table with places set for four people.” “Stones laid in a pattern.”

    Synonyms: laid · Similar: arranged

  5. Being below the horizon.

    “The moon is set.”

    Similar: down

  6. Determined or decided upon as by an authority.

    “Date and place are already determined.” “The dictated terms of surrender.” “The time set for the launching.”

    Synonyms: determined, dictated · Similar: settled

  7. Converted to solid form (as concrete).

    Synonyms: hardened · Similar: hard

Phrases and compounds with "set"

These combinations have meanings of their own, which often cannot be guessed from the single word.

  • set in (verb) Enter a particular state.
  • set on (verb) Attack someone physically or emotionally.
  • set up (verb) Set up or found.
  • set-to (noun) A brief but vigorous fight.
  • tv set (noun) An electronic device that receives television signals and displays them on a screen.
  • jet set (noun) A set of rich and fashionable people who travel widely for pleasure.
  • low-set (adjective) Short and thick; as e.g. having short legs and heavy musculature.
  • saw set (noun) A tool used to bend each alternate sawtooth at a slight angle outward.
  • set gun (noun) A gun that is set to fire on any intruder that comes in contact with the wire that sets it off.
  • set off (verb) Put in motion or move to act.
  • set out (verb) Take the first step or steps in carrying out an action.
  • tea set (noun) A set of china or silverware for serving tea.
  • dead set (adjective) Fixed in your purpose.
  • deep-set (adjective) Having a sunken area.
  • lego set (noun) (trademark) a child's plastic construction set for making mechanical models.
  • mind-set (noun) A habitual or characteristic mental attitude that determines how you will interpret and respond to situations.
