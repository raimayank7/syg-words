Start: meaning, synonyms and examples

Start is used as a verb (14 senses) and noun (8 senses). Its most common meaning is: Take the first step or steps in carrying out an action.

In Hindi
शुरू करना; शुरुआत
Synonyms
get down, begin, get, start out, set about, set out, commence, lead off, depart, part
Opposites
stop, finish
Word family
starter, starting

Start as a verb

  1. Take the first step or steps in carrying out an action.

    “We began working at dawn.” “Who will start?” “Get working as soon as the sun rises!”

    Synonyms: get down, begin, get, start out, set about, set out, commence · Kinds: recommence, strike out, fall, jump off, get to, auspicate, attack, break in

  2. Set in motion, cause to start.

    “The U.S. started a war in the Middle East.” “The Iraqis began hostilities.” “Begin a new chapter in your life.”

    Synonyms: begin, lead off, commence · Kinds: jumpstart, recommence, inaugurate, set off, start

  3. Leave.

    “The family took off for Florida.”

    Synonyms: depart, part, start out, set forth, set off, set out, take off · A kind of: leave · Kinds: take off, roar off, blaze, sally forth

  4. Have a beginning, in a temporal, spatial, or evaluative sense.

    “The DMZ begins right over the hill.” “The second movement begins after the Allegro.” “Prices for these homes start at $250,000.”

    Synonyms: begin · Kinds: erupt, bud, break out, set in, dawn, originate

  5. Bring into being.

    “He initiated a new program.” “Start a foundation.”

    Synonyms: originate, initiate · A kind of: make · Kinds: lead up, set, go back

  6. Get off the ground.

    “Who started this company?” “We embarked on an exciting enterprise.” “I start my day with a good breakfast.”

    Synonyms: start up, embark on, commence · A kind of: begin · Kinds: inaugurate, open

  7. Move or jump suddenly, as if in surprise or alarm.

    “She startled when I walked into the room.”

    Synonyms: startle, jump · A kind of: move · Kinds: shy, boggle, rear back, jackrabbit

  8. Get going or set in motion.

    “We simply could not start the engine.” “Start up the computer.”

    Synonyms: start up · Opposite: stop · Kinds: kick-start, hot-wire, restart, crank, jumpstart

  9. Begin or set in motion.

    “I start at eight in the morning.” “Ready, set, go!”

    Synonyms: go, get going · Opposite: stop · Kinds: go on, get off the ground

  10. Begin work or acting in a certain capacity, office or job.

    “Take up a position.” “Start a new job.”

    Synonyms: take up · Kinds: take office

  11. Play in the starting lineup.

    A kind of: play

  12. Have a beginning characterized in some specified way.

    “My property begins with the three maple trees.” “Her day begins with a workout.” “The semester begins with a convocation ceremony.”

    Synonyms: begin · A kind of: be

  13. Begin an event that is implied and limited by the nature or inherent function of the direct object.

    “Begin a cigar.” “She started the soup while it was still hot.” “We started physics in 10th grade.”

    Synonyms: begin · A kind of: act

  14. Bulge outward.

    “His eyes popped.”

    Synonyms: protrude, pop, pop out, bulge, bulge out, bug out, come out · A kind of: change shape

Start as a noun

  1. The beginning of anything.

    “It was off to a good start.”

    A kind of: beginning · Kinds: adrenarche, menarche, onset, dawn, flying start, opener, alpha, opening

  2. The time at which something is supposed to begin.

    “They got an early start.” “She knew from the get-go that he was the man for her.”

    Synonyms: beginning, commencement, first, outset, get-go, kickoff, starting time, showtime · A kind of: point · Kinds: birth, incipiency, terminus a quo, threshold

  3. A turn to be a starter (in a game at the beginning).

    “He got his start because one of the regular pitchers was in the hospital.” “His starting meant that the coach thought he was one of their best linemen.”

    Synonyms: starting · A kind of: turn

  4. A sudden involuntary movement.

    “He awoke with a start.”

    Synonyms: startle, jump · A kind of: reflex · Kinds: startle response, startle reflex, wince

  5. The act of starting something.

    “He was responsible for the beginning of negotiations.”

    Synonyms: beginning, commencement · Opposite: finish · A kind of: change of state · Kinds: springboard, attack, constitution, introduction, face-off, first step, groundbreaking, housing start

  6. A line indicating the location of the start of a race or a game.

    Synonyms: starting line, scratch, scratch line · A kind of: line

  7. A signal to begin (as in a race).

    “The starting signal was a green light.” “The runners awaited the start.”

    Synonyms: starting signal · A kind of: signal

  8. The advantage gained by beginning early (as in a race).

    “With an hour's start he will be hard to catch.”

    Synonyms: head start · A kind of: advantage

Phrases and compounds with "start"

These combinations have meanings of their own, which often cannot be guessed from the single word.

  • re-start (verb) Start an engine again, for example.
  • start up (verb) Get going or set in motion.
  • start out (verb) Take the first step or steps in carrying out an action.
  • start-off (noun) A start given to contestants.
  • head start (noun) The advantage gained by beginning early (as in a race).
  • jump-start (noun) Starting an automobile engine that has a weak battery by means of jumper cables to another car.
  • kick start (noun) A starter (as on a motorcycle) that is activated with the foot and the weight of the body.
  • kick-start (verb) Start (a motorcycle) by means of a kick starter.
  • fresh start (noun) An opportunity to start over without prejudice.
  • flying start (noun) A racing start in which the contestants are already in full motion when they pass the starting line.
  • racing start (noun) The start of a race.
  • housing start (noun) The act of starting to construct a house.
  • running start (noun) A racing start in which the contestants are already in full motion when they pass the starting line.
  • from start to finish (adverb) Completely.
