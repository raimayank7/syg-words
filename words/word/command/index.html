Command: meaning, synonyms and examples

Command is used as a noun (7 senses) and verb (5 senses). Its most common meaning is: An authoritative direction or instruction to do something.

In Hindi
आदेश
Synonyms
bid, bidding, dictation, control, mastery, instruction, statement, program line, require, dominate
Word family
commandant, commander, commandment

Command as a noun

  1. An authoritative direction or instruction to do something.

    Synonyms: bid, bidding, dictation · A kind of: speech act · Kinds: countermand, order, commission, commandment, injunction, behest, open sesame

  2. A military unit or region under the control of a single officer.

    A kind of: military unit

  3. The power or authority to command.

    “An admiral in command.”

    A kind of: authority

  4. Availability for use.

    “The materials at the command of the potters grew.”

    A kind of: handiness

  5. A position of highest authority.

    “The corporation has just undergone a change in command.”

    A kind of: status

  6. Great skillfulness and knowledge of some subject or activity.

    “A good command of French.”

    Synonyms: control, mastery · A kind of: skillfulness

  7. (computer science) a line of code written as part of a computer program.

    Synonyms: instruction, statement, program line · A kind of: code · Kinds: call, command line, link, macro, system error, toggle

Command as a verb

  1. Be in command of.

    “The general commanded a huge army.”

    A kind of: dominate · Kinds: general, officer

  2. Make someone do something.

    Synonyms: require · A kind of: order · Kinds: charge, requisition, forbid

  3. Demand as one's due.

    “This speaker commands a high fee.” “The author commands a fair hearing from his readers.”

    A kind of: demand

  4. Look down on.

    “The villa dominates the town.”

    Synonyms: dominate, overlook, overtop · A kind of: lie · Kinds: shadow

  5. Exercise authoritative control or power over.

    “Control the budget.” “Command the military forces.”

    Synonyms: control · Kinds: preoccupy, steer, steer, hold one's own, manage, internationalize, hold, hold sway

Phrases and compounds with "command"

These combinations have meanings of their own, which often cannot be guessed from the single word.

  • command key (noun) (computer science) the key on a computer keyboard that is used (in combination with some other key) to type control characters.
  • command line (noun) Commands that a user types in order to run an application.
  • command post (noun) Military headquarters from which a military commander controls and organizes the forces.
  • high command (noun) The highest leaders in an organization (e.g. the commander-in-chief and senior officers of the military).
  • self-command (noun) The trait of resolutely controlling your own behavior.
  • command module (noun) A space module in which astronauts can live and control the spacecraft and communicate with earth.
  • command prompt (noun) (computer science) a symbol that appears on the computer screen to indicate that the computer is ready to receive a command.
  • system command (noun) A computer user's instruction (not part of a program) that calls for action by the computer's executive program.
  • command guidance (noun) A method of controlling the flight of a missile by commands originating from the ground or from another missile.
  • command language (noun) A source language consisting of procedural operators that invoke functions to be executed.
  • command overhead (noun) (computer science) the processing time required by a device prior to the execution of a command.
  • second-in-command (noun) Someone who relieves a commander.
  • allied command europe (noun) A major strategic headquarters of NATO; safeguards an area extending from Norway to Turkey.
  • command line interface (noun) A user interface in which you type commands instead of choosing them from a menu or selecting an icon.
  • command sergeant major (noun) A noncommissioned officer serving as chief administrative officer of a headquarters unit of the Army.
  • air force space command (noun) A command of the United States Air Force that is responsible for defending the United States through its space and intercontinental ballistic missile operations.
